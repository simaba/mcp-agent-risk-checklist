# Public Release Checklist

Before making this repository public:

- [ ] Confirm all tool manifests, permissions, logs, incidents, risk reviews, and mitigations are fictional or fully sanitized.
- [ ] Remove real endpoints, credentials, server configuration, tenant/workspace identifiers, customer data, audit records, and proprietary policies.
- [ ] Review all branches, full git history, issues, pull requests, comments, Actions logs/artifacts, releases, tags, attachments, and repository metadata.
- [ ] Confirm the schema and example use only fictional names and do not imply a real security approval.
- [ ] Confirm the README, scoring guidance, and mitigations describe the repository as a practitioner aid—not a scanner, certification, or production-readiness assessment.
- [ ] Validate the example against the schema before publishing a release.
- [ ] Create a draft release and inspect notes/assets before publishing.

This review does not replace qualified security, privacy, legal, compliance, or system-owner approval.
