# Changelog

## [0.1.0] - 2026-06-25

### Added

- Practical checklist for tool scope, permissions, data exposure, prompt injection, auditability, failure modes, and human oversight.
- Machine-readable fictional risk-review schema.
- Filled fictional review example.
- Likelihood/impact scoring guidance and decision rules.
- Common mitigation catalogue.

### Scope

This is a practitioner checklist and review aid. It is not an automated security scanner, formal security review, compliance certification, or production-readiness authority.
